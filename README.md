# LLM Telegram Bot

LLM Telegram Bot 是一个可自托管的 Telegram 聊天机器人，使用 Go 开发，通过 OpenAI 兼容 API 接入模型。你可以在私聊或群聊与它对话，也可以请它跟进关心的事。

## 核心能力

- **流式对话与群聊**。实时更新回复，用历史记录和摘要延续对话。在群里可通过 @提及触发，也可启用相关性判断。
- **语音、图片与文档**。转写语音，理解图片，提取 PDF、办公文档和纯文本内容。可以启用语音播报和贴纸回复。
- **角色记忆（Memory Book）**。角色可以在对话中积累和修订记忆。私聊事实默认只用于本人私聊，群内事实默认只用于原群。用户可以把一条私聊结论分享给指定群，也可以撤回。
- **主动聊天与长期跟踪**。角色会根据近期互动决定是否主动开口，也能通过已配置的来源核实发布或活动进展，再向约定的接收方更新。本人可明确授权一次性日历创建。
- **MCP 工具**。支持全局与个人连接。用户可授权在指定群查询个人网络工具并分享结果。可以按需加载工具定义。
- **提醒与定时任务**。用户可以用自然语言创建一次性或重复提醒。管理员可以按聊天配置定时任务。
- **管理与用量**。支持管理员私聊配置面板、用户和群组白名单、每日用量配额，以及只读 SSH 看板。
